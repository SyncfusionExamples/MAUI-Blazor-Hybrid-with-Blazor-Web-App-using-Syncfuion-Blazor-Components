# MAUI Blazor Hybrid with Components

A comprehensive example demonstrating how to build cross-platform applications using **[Blazor Components](https://www.syncfusion.com/blazor-components)** with **.NET MAUI Hybrid** architecture, combined with an **ASP.NET Core Blazor Web App** backend. This solution showcases code sharing between native and web platforms while leveraging powerful UI components.

## Overview

This project demonstrates a complete architecture for building cross-platform applications using modern Microsoft technologies:

- **MauiHybridWebApp** – A .NET MAUI application that runs natively on mobile and desktop platforms using embedded Blazor web components
- **MauiHybridWebApp.Shared** – Shared Razor components, pages, and services used across both MAUI and Web platforms
- **MauiHybridWebApp.Web** – An ASP.NET Core Blazor Server app that can be deployed independently

The shared UI is built with **Blazor Components**, enabling a consistent, professional user interface across all platforms.

## Features

- **Cross-Platform Support** – Target Android, iOS, macOS, Windows, and Web from a single project
- **Shared Razor Components** – Code reuse across native and web platforms
- **UI Components** – Professional data grids, charts, and interactive controls
- **Hybrid Architecture** – Blazor components embedded in native MAUI apps
- **Web Deployment Ready** – Same components run on ASP.NET Core Blazor Web App
- **Responsive Design** – Adapts to mobile, tablet, and desktop form factors
- **Data Management** – Example data binding and component integration

## Prerequisites

- [.NET SDK 8.0](https://dotnet.microsoft.com/download/dotnet/8.0) or later
- [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
- [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/MAUI-Blazor-Hybrid-with-Blazor-Web-App-using-Syncfusion-Blazor-Components.git
cd MAUI-Blazor-Hybrid-with-Blazor-Web-App-using-Syncfusion-Blazor-Components
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.
